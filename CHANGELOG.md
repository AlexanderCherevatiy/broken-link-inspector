# Changelog

## 1.0.0

- Added on-demand bookmark scanning and optional read access to bookmarks.
- Added selection and retry for missing or uncertain links.
- Added per-result sources and the ability to highlight available links on their original page.
- Expanded human-readable HTTP results while keeping ambiguous failures distinct from confirmed missing responses.
- Added 20 interface languages, localization checks, and Arabic right-to-left layout.
- Added separate Microsoft Edge and Mozilla Firefox packages.
- Added a network disclosure, additional protections for sensitive URLs, and a control to clear local reports.
- Added source build instructions, license notices, store submission materials, and CI.

## 0.1.0

- Added user-initiated page scans, optional host grants, categorized results, cancellation, and CSV export.
- Added English and Russian, local reports, and light, dark, and system themes.
- Updated the popup and report to the shared blue-and-white design.
