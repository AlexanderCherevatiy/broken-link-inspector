# Broken Link Inspector

Broken Link Inspector проверяет HTTP- и HTTPS-ссылки на открытой странице или в закладках. Расширение показывает ответы сайтов, позволяет повторно проверить выбранные ошибки и сохранить отчёт в CSV. Оно работает во вкладке браузера и бесплатно для пользователей.

## Локальная установка

Выберите сборку для нужного браузера. Минимальные версии по манифестам — Edge 154 и Firefox 140 для настольных систем. Статус пакетов указан в [инструкции релиза](RELEASE.md).

- **Microsoft Edge**. Откройте `edge://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите `dist/edge`. [Инструкция Edge](https://learn.microsoft.com/en-us/microsoft-edge/extensions-chromium/getting-started/extension-sideloading)
- **Mozilla Firefox**. Откройте `about:debugging#/runtime/this-firefox`, нажмите **Загрузить временное дополнение** и выберите Firefox XPI или файл `dist/firefox/manifest.json`. Временная установка действует до перезапуска Firefox. Для обычной установки нужен подписанный пакет. [Инструкция Firefox](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Your_first_WebExtension#installing)

## Проверка ссылок

1. Откройте обычную страницу HTTP или HTTPS и нажмите **«Проверить текущую страницу»** в меню расширения. Для проверки закладок выберите соответствующую кнопку и разрешите браузеру предоставить доступ на чтение.
2. Прочитайте уведомление о сетевых запросах. Проверка обращается к сайту, на который ведёт ссылка. Этот сайт может увидеть проверяемый URL и ваш IP-адрес. Разрешите доступ к хостам, которые хотите проверить.
3. Изучите результаты и их источники. Отметьте ошибочные или неопределённые ссылки и запустите повторную проверку. Кнопка перехода к ссылке прокручивает исходную страницу и подсвечивает элемент, если он доступен. У закладок исходной страницы нет.
4. Нажмите **«Остановить»**, чтобы отменить активные проверки, или **«Скачать CSV»**, чтобы сохранить отчёт. В настройках доступны смена языка и темы, режим локальных тестов и очистка сохранённых отчётов.

| Результат | Что означает |
| --- | --- |
| Работает | Сайт ответил HTTP 2xx. |
| Не найдена | Сайт ответил HTTP 404 или 410. |
| Перенаправление | Сайт ответил HTTP 3xx. Адрес перехода показан, если браузер его предоставил. |
| Неясно | Неоднозначный ответ, например HTTP 403, 429 или 5xx, тайм-аут либо сетевая ошибка. |
| Не проверена | Нет разрешения, адрес исключён или проверка ещё не выполнена либо прервана. |

## Особенности

- При запуске сохраняется снимок ссылок из основного документа, до 1 000 уникальных адресов. Вложенные фреймы и Shadow DOM в проверку не входят.
- Проверка работает, пока открыта вкладка отчёта. Одновременно проверяются до трёх ссылок на отчёт, с тайм-аутом в восемь секунд для каждой ссылки. После прерывания завершённые результаты можно открыть и проверить снова.
- Отчёт показывает первый ответ перенаправления. По его адресу расширение автоматически не переходит.
- Локальные сети исключены из обычной проверки. Для контролируемого стенда выделен режим, разрешающий отдельные loopback-адреса.
- Отчёты и настройки хранятся в браузере. Экспортированный CSV остаётся в месте, куда вы его скачали. [Политика конфиденциальности](PRIVACY.md#русская-версия)
- Интерфейс доступен на 20 языках. Переводы с отметкой о ревью требуют проверки носителем языка. [Как помочь с переводами](CONTRIBUTING.md#translations)
